# Multi-Agent Project Strategy System (JADE + Gemini)

A Java multi-agent framework built with **JADE** and **Google Gemini API** that collaborates to analyze project ideas, conduct market and risk assessments, formulate business strategy roadmaps, and generate formatted PDF and Word reports.

---

## Prerequisites

* **Java Development Kit (JDK)**: Java 17 or higher.
* **Build System**: Pure Java project (No Maven or Gradle required).
* **Dependencies**: External `.jar` libraries placed inside the `lib/` directory.

### Required JARs in `lib/`

Ensure all required dependency JARs are present in your `lib/` folder:

* **JADE Framework**: `jade.jar` (v4.6)
* **JSON Parsing**: `json-*.jar` (`org.json`)
* **Apache PDFBox 3.x**:
  * `pdfbox`
  * `pdfbox-io`
  * `fontbox`
  * `commons-logging`
* **Apache POI 5.x**:
  * `poi`
  * `poi-ooxml`
  * `poi-ooxml-lite`
  * `xmlbeans`
  * `commons-collections4`
  * `commons-compress`
  * `commons-io`
  * `commons-codec`
  * `commons-math3`
  * `log4j-api`
  * `curvesapi`
  * `SparseBitSet`

##  Agent Architecture & Workflow

The platform creates a single JADE container (`MainContainer.java`) that boots five autonomous agents working in orchestration:

```
                  ┌─────────────────┐
                  │   User Input    │
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │  ManagerAgent   │ (Orchestrator)
                  └───┬─────────┬───┘
                      │         │
          ┌───────────┘         └───────────┐
          ▼                                 ▼
┌───────────────────┐             ┌───────────────────┐
│ BusinessAnalyst   │             │   MarketRisk      │ (Parallel Execution)
└─────────┬─────────┘             └─────────┬─────────┘
          │                                 │
          └───────────┐         ┌───────────┘
                      ▼         ▼
                  ┌─────────────────┐
                  │  StrategyAgent  │ (Synthesis)
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │   ReportAgent   │ (Document Generation)
                  └────────┬────────┘
                           │
                 ┌─────────┴─────────┐
                 ▼                   ▼
         ┌───────────────┐   ┌───────────────┐
         │  strategy.pdf │   │ strategy.docx │
         └───────────────┘   └───────────────┘
```

1. **ManagerAgent (`manager`)**: Coordinates the execution pipeline, collects inputs, handles parallel dispatch, merges outputs, and manages lifecycle shutdown.
2. **BusinessAnalystAgent (`businessAnalyst`)**: Prompts Gemini to analyze target user segments, problem statements, measurable objectives, and functional requirements.
3. **MarketRiskAgent (`marketRisk`)**: Prompts Gemini to analyze market size, trends, competitors, and risk factors (with likelihood, impact, and mitigations).
4. **StrategyAgent (`strategyAgent`)**: Synthesizes output from both business and market analysis agents to establish key strategic priorities and an implementation roadmap.
5. **ReportAgent (`reportAgent`)**: Receives the consolidated JSON dataset and delegates file rendering to `PdfService` and `WordService`.

## Configuration & Features (`Config.java`)

All system toggles, API properties, and paths are centrally controlled in `src/app/Config.java`:

* **Output Reports**: Generated by default at `output/reports/strategy.pdf` and `output/reports/strategy.docx`.
* **Execution Logs**: Automatically logged to `output/logs/run.log` via thread-safe `Logger`.
* **API Rate Limiting**: Inter-call throttling configured by `GEMINI_MIN_INTERVAL_MS` (default: `15000` ms / 15 seconds) to ensure compliance with API limits.
* **Model Fallbacks**: Default model is `gemini-3.1-flash-lite`, with built-in failover to secondary models in case of `429` (Rate Limit) or `503` (Service Unavailable) responses.
* **Report Branding**: Optional inclusion of logo (`assets/logo.png`) and custom report links.
